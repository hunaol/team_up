# 比赛队招募 · 校园招募平台

校园内的比赛队友招募平台：学生用「学号 + 姓名」登录发布招募 / 找队伍，系统按技能、赛事、年级自动算匹配度，
支持申队附简历与站内私信；管理员在后台查看运营数据、管理用户与帖子。
前端 Vue 3 + Vite（移动端优先，桌面端保留侧栏布局），后端 FastAPI + SQLite。

## 目录结构

```
backend/                  FastAPI 服务
  main.py                 入口（建表 / 迁移 / 种子管理员 / 挂载路由）
  models.py               数据模型：User / Post / Token / Admin / Favorite / Application / Message
  schemas.py              入参校验 + 富文本白名单净化
  competitions.py         高水平竞赛名录（90 场，含别名归一）
  matching.py             匹配度算法（技能 45% / 比赛 25% / 年级 15% / 专业 15%）
  routes_user.py          注册 / 登录 / 退出 / 当前用户 / 个人资料
  routes_post.py          招募帖 CRUD、下架、重新发布、招满、收藏、申请、候选人
  routes_message.py       站内私信：会话列表 / 会话详情 / 发送 / 未读数
  routes_meta.py          名录与标签字典：/api/meta、别名归一查询
  routes_stats.py         首页统计概览
  routes_admin.py         管理后台：统计、用户、帖子
  run_tests.py            接口集成测试
  _seed.py                演示数据（可重复执行，会清空 posts / favorites / applications / messages）
  _clean.py               清掉测试账号，跑测试前使用
frontend/                 Vue 3 + Vite 前端
  src/views/              页面（首页 / 广场 / 详情 / 发布 / 我的发布 / 收藏 / 资料 / 消息 / 登录 / 后台）
  src/components/         通用组件（侧栏、顶栏、移动端底部标签栏、招募卡片、匹配徽标、富文本编辑器等）
  src/responsive.css      移动端适配（≤860px 收起侧栏、启用底部标签栏与单列布局）
  scripts/shots.mjs       开发用：headless Chrome 逐页截图（桌面）
  scripts/shots-mobile.mjs 开发用：移动端 390×844 截图
  scripts/probe-mobile.mjs 开发用：移动端横向溢出 / 控制台错误体检
```

## 启动

后端（默认 8000）：

```bash
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

前端（默认 5173，已配置 `/api` 代理到 8000）：

```bash
cd frontend
npm install
npm run dev
```

打开 http://localhost:5173 （Vite 监听 IPv6，请用 localhost 而非 127.0.0.1）。
手机同网段可访问 `http://<本机 IP>:5173` 预览移动端布局。

## 账号

- 学生：直接输入学号 + 姓名即可登录 / 注册，无需密码。跑过 `_seed.py` 的演示库里有 6 个演示账号，
  例如 `2024413435 / 韩涛`、`2024411108 / 李思远`（线上生产库已清空时无演示账号）。
- 管理员：`admin / admin123`，入口在登录页右下角「管理员入口」，或直接访问 `/admin/login`。

## 常用命令

```bash
# 重置演示数据（6 个用户 + 8 条结构化招募 + 申请 + 私信）
cd backend && python _seed.py

# 跑接口测试（会创建测试账号，跑完可用 _clean.py 清理）
cd backend && python run_tests.py

# 前端生产构建
cd frontend && npm run build

# 截图 / 体检（需先启动 dev server 与 headless Chrome，端口 9222）
cd frontend && node scripts/shots.mjs ../.shots
cd frontend && node scripts/shots-mobile.mjs .shots-mobile
cd frontend && node scripts/probe-mobile.mjs
```

## 功能

**信息检索**

- 竞赛名录统一名称：内置 90 场高水平竞赛及别名，`正大杯 / 市调 / 市调大赛` 都会归一到「全国大学生市场调查与分析大赛」，
  发帖、筛选、个人意向都用同一套标准名，避免各写各的导致漏帖；名录外的比赛可自由填写。
- 竞赛名录页（`/competitions`）：按学科分类浏览全部 90 场，支持按标准名与别名搜索、按分类筛选，
  标出「几队在招」并可只看有队伍在招的比赛，点进去直接跳转广场并带上该比赛的筛选条件。
- 结构化发布：参加的比赛、比赛阶段（刚组队 / 校赛冲刺 / 省赛备战 / 国赛备战）、缺什么位置（16 类技能标签）、
  年级要求、专业要求。「一条条写清楚」的字段都可被检索。
- 高级筛选：比赛（支持别名搜索）、缺什么位置、年级要求、比赛阶段，条件走 URL query 可分享 / 刷新保持；
  已选条件以 chip 展示，可单个移除或一键清空。
- 排序：最新发布 / 匹配优先（登录后可用）。

**个人资料与匹配**

- 我的资料：年级、专业、擅长 / 意向位置、意向比赛、一句话介绍、简历、联系方式、是否开放匹配，含资料完整度。
- 匹配度算法：技能 45% + 同赛事 25% + 年级 15% + 专业 15%，卡片与详情页显示「匹配 N%」及匹配 / 缺失原因；
  资料为空时不显示假百分比。
- 首页「为你推荐」按匹配度取前 3（≥45% 才展示），广场可切换「匹配优先」排序。
- 队长视角：招募详情页有「匹配候选人」，系统按缺的位置给「找队伍」帖排序。

**申队与私信**

- 申请加入：可写自荐语并附简历（自动带出个人资料里的简历），提交后落库为 `pending`。
- 队长处理：详情页「收到的申请」可查看申请人年级、专业、技能、匹配度、简历，一键通过 / 婉拒。
- 站内私信：会话列表（未读数）、会话详情、发送消息；顶栏铃铛与侧栏 / 底部标签栏都有未读角标。

**移动端**

- ≤860px 收起左侧栏，改为底部标签栏（首页 / 广场 / 发布凸起按钮 / 消息 / 我的），页面单列、卡片可点区更大。
- 筛选面板、申请弹窗在移动端变为底部抽屉；消息列表与聊天在移动端单栏切换并带返回按钮。
- 后台在移动端显示顶部横向导航，不显示学生标签栏。

**管理端**

- 数据概览：近 7 / 30 / 90 天，注册用户 / 发布招募 / 参与人数 / 成功率环比，发布趋势折线图与状态分布环形图
- 用户管理：搜索、状态筛选、分页、改姓名、禁用 / 启用
- 帖子管理：搜索、类型 / 状态筛选、下架违规招募

## 说明

- 招募帖 30 天自动过期（读取时按 `created_at` 计算，不落库）。
- 联系方式仅登录用户可见；未登录时接口直接返回 `contact: null`。
- 富文本描述在服务端做白名单净化：仅保留 `b / i / u / br` 与本站上传的 `img`（`src` 必须是 `/api/uploads/...`），其余标签与属性全部丢弃。
- 上传限制：jpg / png / webp / gif，单张 ≤ 2MB。
- 旧库升级：`main.py` 启动时用 `PRAGMA table_info` 检测并 `ALTER TABLE ADD COLUMN` 补齐新增字段，无需手动迁移。
- 竞赛名录来源：《全国84项大学生竞赛》名录（84 项，按计算机专业相关度分类）与「小犁竞赛时间表」，只取**标准名与别名**做归一，
  不展示报名时间与时间表；改名、简称、往届叫法都作为别名挂在同一条目上（如 `工程训练综合能力竞赛 → 中国大学生工程实践与创新能力大赛`）。
  名录是纯数据（`competitions.py`），新增比赛只需往 `COMPETITIONS` 里加一条，前端与接口自动生效。
